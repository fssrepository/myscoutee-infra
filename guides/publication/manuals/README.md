# Infrastructure configuration lab guide

The branded PDF explains basic configuration-management terms, the lab
components, Vagrant versus Terraform, a seven-step comparison method,
annotated Ansible/Puppet terminal output, the runbook and the MyScoutee edge
use case. The editable source is
`build-guide.py`; the heart asset follows the other MyScoutee publication
manuals.

Regenerate with:

```sh
python3 guides/publication/manuals/build-guide.py
```

ReportLab and DejaVu Sans are required. Render every page with Poppler after
editing to check layout. The guide describes a synthetic edge, not a connected
MyScoutee deployment.
